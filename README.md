# School Cool

Бесплатная интерактивная школа по всем предметам для школьников всего мира.

## Прототип урока «Мощность»

`prototype/lesson-power/index.html` — концепт одного урока по физике. Один экран: 3D-опыт на Three.js занимает сцену, рядом карточка урока, которая показывает по одному шагу.

1. **Угадай** — какой мотор мощнее. Выбор ответа сразу запускает опыт.
2. **Проверь** — моторы поднимают ящики, над ними идут секундомеры.
3. **Пойми** — ответ с формулой N = A / t, затем ползунки массы и времени.

Синим выделено всё, на что можно нажать. Сцену можно вращать.

Открыть: просто откройте файл в браузере (Three.js и шрифты грузятся с CDN).

## Концепции книги

`prototype/book-concepts/index.html` — 8 визуальных концепций «книга, из страницы которой вырастает опыт»: поп-ап из бумаги, чертёж оживает, под стеклянным куполом, остров на странице, ночная книга, пластилин, бумажный театр, окно в страницу. Каждую можно повернуть и нажать.
