# School Cool

Бесплатная интерактивная школа по всем предметам для школьников всего мира.

## Прототип урока «Мощность»

`prototype/lesson-power/index.html` — концепт одного урока по физике в формате школы:

1. **Предскажи** — ученик выбирает ответ до того, как узнает правильный.
2. **Проверь опытом** — 3D-сцена на Three.js: два моторчика поднимают ящики, секундомеры считают время.
3. **Пойми почему** — клапан с объяснением открывается только после попытки.
4. **Поэкспериментируй** — ползунки массы и времени, мощность считается по формуле N = A / t.

Открыть: просто откройте файл в браузере (Three.js и шрифты грузятся с CDN).
